Connect KAI Core

In KAI Core, open Settings → KAI account & credits, then choose Connect to my KAI account. Open the link beside the code so it arrives on the correct page. Only approve a device you recognize.

Already using Core credits? Choose Link to my website account in Core, then Link this Core wallet after sign-in. For a different website login, Core shows the current account and a Sign out button. Signing out preserves your wallet, credits, chats and files. If a code expires, choose Get a new code in Core.

# Tools and MCP

Install **Tools** through Core’s Plugins page, then open the installed feature from Apps.

Developer utilities, MCP integrations, teams, pipelines and reusable tool setups belong to the Tools plugin. Review each integration before granting access.

[Plugin repository and release notes](https://github.com/therexdev/kai-plugin-tools)

Core and plugin updates are separate. Review publisher permissions before installation and action approvals before changes. Native plugins are trusted code with full access available to KAI.

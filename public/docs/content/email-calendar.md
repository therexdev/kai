# Email, calendar, memory

## Email

**Tools & accounts → Email** connects any IMAP/SMTP mailbox — Gmail works with an [app password](https://support.google.com/accounts/answer/185833).

- Read your inbox in the app; the AI summarizes threads and drafts replies.
- **Sending is always manual** — the AI drafts, you press send.
- Credentials are encrypted with your OS keychain where available.

## Calendar

Connect any CalDAV calendar. See upcoming events; the AI can create events — with a confirmation step before anything lands in your calendar.

## Memory

The Memory panel shows everything the AI has remembered about you. Each entry can be deleted. Memory is a local file on your disk; it never syncs anywhere.

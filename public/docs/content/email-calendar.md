# Connections and memory

Install **Connections and Brain** through Core’s Plugins page, then open the installed feature from Apps.

Connections owns linked app accounts and permissions. Brain owns memories, goals and selected sources. Install Assistant to use supported context and actions in conversations. Reconnect accounts after moving from Alpha; its connected-account data is not automatically imported.

[Plugin repository and release notes](https://github.com/therexdev/kai-plugin-connections)

Core and plugin updates are separate. Review publisher permissions before installation and action approvals before changes. Native plugins are trusted code with full access available to KAI.

# Koinos Code

Install **Koinos Code** through Core’s Plugins page, then open the installed feature from Apps.

Work on projects and review proposed code, file edits and commands before applying them. Keep wallet and application profile folders out of coding workspaces.

[Plugin repository and release notes](https://github.com/therexdev/kai-plugin-code)

Core and plugin updates are separate. Review publisher permissions before installation and action approvals before changes. Native plugins are trusted code with full access available to KAI.

# Chat with KAI

Core includes simple chat with your installed local models. Install **KAI Assistant** for the fuller conversation workspace, voice and desktop companion.

Choose the model and route deliberately: local models run on your computer, network AI uses the credit service, and your own API providers bill separately. Check model readiness before a request and use Stop to cancel work.

Assistant, Brain and Connections are independent plugins. Install Brain for saved context and Connections for supported account actions. Review permissions and proposed changes before allowing an action.

Local-Only blocks network AI routes; native plugins are trusted code, so their own network and integration behavior also matters.

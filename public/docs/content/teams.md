# Agents and workflows

Install **Workflows** through Core’s Plugins page, then open the installed feature from Apps.

Create visual agents and workflows with steps, branches, schedules and approval points. Keep Core running for local scheduled work. Agent Network is a separate plugin for isolated services and free jobs; paid rentals are not enabled.

[Plugin repository and release notes](https://github.com/therexdev/kai-plugin-workflows)

Core and plugin updates are separate. Review publisher permissions before installation and action approvals before changes. Native plugins are trusted code with full access available to KAI.

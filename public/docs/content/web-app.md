# Website and desktop access

**KAI Core Beta is the current desktop app.** [Download Core and plugins](https://koinosai.com/beta).

The website provides documentation, mainnet public network status, sign-in and existing account management. Current mainnet credits, provider rewards and model eligibility are shown inside Core.

The [legacy web workspace](https://koinosai.com/app) retains existing account data and grants. It is not the Core Beta mainnet credit interface. Do not use its old KAI pricing or the Alpha dashboard to estimate current KOIN earning.

Use [Account](https://koinosai.com/account) to review or revoke existing website sessions and grants. Use Core for its wallet and credit session, and reconnect plugin integrations in the plugin that owns them.

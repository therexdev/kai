Get comfortable in Core

  1. Install and open KAI Core Beta

    Use the Windows Setup installer or the Mac build for your processor. On 64-bit Raspberry Pi OS or Linux, download the installer and run bash ~/Downloads/Install-KAI-Core-Pi.sh from your desktop account without sudo. It adds desktop and menu launchers.

  2. Bring your models and wallet

    Close Alpha, including its tray icon. In Core, open Settings → Migrate from Koinos AI Alpha, select Models, Wallet or both, and review the transfer. Existing Core wallets are not overwritten. Plugin data and connected accounts are not migrated.

    Follow the illustrated transfer guide →

  3. Choose a model

    Open Models and install or migrate a compatible local model. Local inference runs on your computer. Choose network AI when you want another provider to serve the request; check available models and pricing in Core.

  4. Add your plugins

    Open Plugins, review each plugin’s publisher and permissions, install it, then open it from Apps. Start with Assistant for the companion and advanced chat. Add Brain, Workflows or Connections as you need them.

Mainnet KOIN earning is live

Open Earn KOIN, complete the wallet and provider setup shown in Core, select supported installed models, and enable sharing. Keep your computer online and check its provider status and reward feed.

Rewards depend on eligibility, availability, accepted work and the network’s reward policy. An estimate is not a confirmed payout. View your own credits and rewards in Core; public network stats show provider presence, not a promise that every model can serve a paid request.

AI earning and block production are separate

The optional Koinos Node plugin manages a blockchain node. We recommend a new, dedicated Node wallet, not your KAI Core wallet. Node migration moves chain data only; wallets, funds and production keys need separate setup.

Build a plugin of your own

Third-party developers use the same public SDK as KAI plugins. Start with a sandboxed example, or use a native service when your feature needs deeper integration. Package and sign your plugin before sharing it.

A few things to know

Update deliberately

Windows Setup and supported user-owned Linux AppImages can download verified updates inside Settings. Restart and install is your choice. macOS and portable builds use the release page. Plugins update separately.

Keep your account boundaries clear

Your website account manages website sign-in, linked devices and existing web access. Core’s credit session, wallet and plugin accounts are separate. Website sign-in does not automatically import credits or plugin data.

Beta feedback matters

Report the Core or plugin version, platform and steps to reproduce. Remove private keys, passwords and personal information before attaching diagnostics.
